# SENTINEL-X

Self-evolving cyber exposure twin with counterfactual defense optimization.

SENTINEL-X models **authorized** external exposure as a temporal graph. It does not hack, spray credentials, or exploit. Every important number traces to evidence and deterministic engines. The assistant may only cite those facts.

## What to try

1. Open the Northshore State University demo twin.
2. Inspect assets, evidence, and the attack graph.
3. Select a critical modeled path — note **risk vs confidence**.
4. Run an MFA simulation (before/after, residual risk).
5. Ask for a minimum defense strategy.
6. Open drift and SENTINEL-X Exposure Momentum (project metric).
7. Generate a report. Ask the analyst why a path is ranked.

Language in the product is disciplined: observed, modeled, potential, requires verification. Not “breached.”
